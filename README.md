# Biblioteka Ane i Jusufa Kalamperović

Finalni GitHub Pages paket.

Sadrži:
- `index.html`
- `style.css`
- `app.js`
- `books.json` (526 knjiga)
- `porodicno-stablo-kalamperovici.pdf`
- `preci-i-potomci-ana-kalamperovic.pdf`
- `.nojekyll`

## Šifra

Podrazumijevana šifra je `kalamperovic`.

Za promjenu otvori `app.js` i promijeni:

```js
const SITE_PASSWORD = 'kalamperovic';
```

## GitHub Pages

Uploaduj sadržaj ovog foldera u root GitHub repozitorijuma. Zatim otvori:

`Settings -> Pages -> Build and deployment -> Deploy from a branch -> main -> /(root) -> Save`

PDF fajlovi se prikazuju kao kartice u sekciji **Porodična arhiva**, nakon unosa šifre.
